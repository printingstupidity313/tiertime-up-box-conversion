genral tools eg: screwdriver, drill, scissors, pliers,wire strippers, idk a hammer etc.
screws just buy a m3-m6 pack about 10 each 
zip ties *
24v 10ah power supply 
motherboard from an ender 3 or as i am using a generic one make sure it can run marlin or klipper and has 4 axis
